# Distribution provenance

SkillShelf packages the author's learning, coding, thinking, and career workflows from their installed skill collection. Public copies replace machine-specific paths and remove personal state; the original installed skills are not modified.

## Excluded third-party skills

The following installed skills were identified in the local installation lockfile as originating from `mattpocock/skills` and are not redistributed here:

- `batch-grill-me`
- `code-review`
- `codebase-design`
- `diagnosing-bugs`
- `grill-me`
- `grill-with-docs`
- `grilling`
- `handoff`
- `improve-codebase-architecture`
- `to-spec`

The upstream collection remains available at https://github.com/mattpocock/skills. These exclusions do not uninstall local copies.

## Excluded private and generated material

Personal background notes, authored learning records, interview history, question-bank material, local project pointers, setup ownership markers, caches, source books, credentials, and personal workspaces are not part of this repository. Illustrative resume examples have been generalized.

## Learning runtime

`runtime/` contains the author's deterministic Python implementation from the Knowledge Base project, including source processing, retrieval, durable learning records, and profile approval tools. It includes no subject corpus or approved personal facts. The public skill copies have portability changes; the runtime retains its own tests.

## Excluded Job Atlas skills

Job Atlas has its own repository, packaging, and installation. These seven installed skills are deliberately excluded from SkillShelf:

- `draft-outreach`
- `enrich-companies`
- `enrich-jobs`
- `find-profile-links`
- `full-pipeline`
- `mock-interview`
- `tailor-resumes`

See [Job Atlas](https://github.com/yati989/job-atlas) for those workflows. SkillShelf does not bundle its application, career data, or outreach tooling.
