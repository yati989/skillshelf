# Example requests

Invoke a skill by name in your coding agent. Supply the referenced code or document when needed.

## auto-complete

Turn comments, pseudocode, or broken code into a working implementation.

```text
Use $auto-complete to implement this pseudocode in Python and explain the result.
```

## brainstorming-agent

Explore ideas, test assumptions, and compare options through discussion.

```text
Use $brainstorming-agent to help me compare two approaches to my side project.
```

## code-concept-map

Build an interactive tree of concepts actually used in a repository.

```text
Use $code-concept-map to map the engineering concepts in this repository.
```

## code-execution-path

Trace a task through a concise chain of linked execution steps.

```text
Use $code-execution-path to trace what happens when a user submits this form.
```

## idea-council-agent

Evaluate an idea through four sequential expert gates.

```text
Use $idea-council-agent to evaluate this project idea before I build it.
```

## interviewer-agent

Practise concept-first interviews with bounded transfer probes and saved feedback.

```text
Use $interviewer-agent for a backend engineering interview based on this project.
```

## language-tutor

Build and resume a spoken-language course with practice and assessments.

```text
Use $language-tutor to plan a beginner spoken Spanish course.
```

## personal-context

Manage a shared personal profile through exact proposals and explicit approval.

```text
Use $personal-context to show the keys in my approved profile.
```

## reading-agent

Read supplied books or passages in source-grounded parts with checkpoints.

```text
Use $reading-agent to read this PDF with me, one chapter at a time.
```

## self-help-agent

Offer explicitly requested, research-informed supportive conversation.

```text
Use $self-help-agent to help me think through a recurring frustration.
```

## structure-map

Map a library's main abstractions and everyday entry points.

```text
Use $structure-map to show how scikit-learn is organized.
```

## student-agent

Practise learning by teaching a curious student who probes your explanation.

```text
Use $student-agent. I will explain database indexes; ask about gaps in my reasoning.
```

## tutor-code-file

Explain one code file through its purpose, structure, and execution flow.

```text
Use $tutor-code-file to explain this file and its important dependencies.
```

## tutor-codebase

Teach transferable engineering concepts from real code and preserve completed lessons.

```text
Use $tutor-codebase to teach the concepts behind this repository.
```

## tutor-plain-language

Explain a bounded piece of code or prose in clear, concrete language.

```text
Use $tutor-plain-language to explain this function with a tiny example.
```

## tutor-source-grounded

Build a persistent evidence base, teach from approved sources, and assess understanding.

```text
Use $tutor-source-grounded to plan a course on computer networking.
```

## tutor-visual

Explain code, architecture, and data flow with grounded visualizations.

```text
Use $tutor-visual to show how data moves through this service.
```
