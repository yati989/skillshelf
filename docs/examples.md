# Things to try

Choose a skill and give your agent a request like one of these. Include the code, document, or idea you want to work on.

## auto-complete

Turn rough notes, pseudocode, or broken code into a working program.

```text
Use $auto-complete to implement this pseudocode in Python and explain the result.
```

## brainstorming-agent

Talk through an idea, compare your options, and decide what to try next.

```text
Use $brainstorming-agent to help me compare two approaches to my side project.
```

## code-concept-map

See which programming concepts a project uses in an interactive map.

```text
Use $code-concept-map to map the engineering concepts in this repository.
```

## code-execution-path

Follow a request or action through the code, step by step.

```text
Use $code-execution-path to trace what happens when a user submits this form.
```

## idea-council-agent

Test a project idea from four angles: purpose, demand, cost, and how to build it.

```text
Use $idea-council-agent to evaluate this project idea before I build it.
```

## interviewer-agent

Practise an interview for your role or project and get feedback on your answers.

```text
Use $interviewer-agent for a backend engineering interview based on this project.
```

## language-tutor

Learn to speak a language through guided lessons, conversation, and review.

```text
Use $language-tutor to plan a beginner spoken Spanish course.
```

## personal-context

Keep your goals and preferences available across sessions, with changes you approve.

```text
Use $personal-context to show the keys in my approved profile.
```

## reading-agent

Read a book or PDF together, discuss each part, and save where you stopped.

```text
Use $reading-agent to read this PDF with me, one chapter at a time.
```

## self-help-agent

Talk through difficult feelings or recurring frustrations and explore ways to cope.

```text
Use $self-help-agent to help me think through a recurring frustration.
```

## structure-map

Get an overview of a code library: its main parts, how they connect, and where to start.

```text
Use $structure-map to show how scikit-learn is organized.
```

## student-agent

Check your understanding by teaching a curious student who asks about gaps.

```text
Use $student-agent. I will explain database indexes; ask about gaps in my reasoning.
```

## tutor-code-file

Understand what a code file does, how it works, and which parts matter.

```text
Use $tutor-code-file to explain this file and its important dependencies.
```

## tutor-codebase

Learn software engineering by exploring real code, with saved lessons and practice.

```text
Use $tutor-codebase to teach the concepts behind this repository.
```

## tutor-plain-language

Get a clear explanation of code or text, with small examples you can follow.

```text
Use $tutor-plain-language to explain this function with a tiny example.
```

## tutor-source-grounded

Study a subject using sources you choose, with a course plan, lessons, and tests.

```text
Use $tutor-source-grounded to plan a course on computer networking.
```

## tutor-visual

Understand code and systems through diagrams that show how the pieces work together.

```text
Use $tutor-visual to show how data moves through this service.
```
